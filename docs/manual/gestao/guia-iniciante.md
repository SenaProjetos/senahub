# Guia de Gestão para iniciantes

O guia de formação de Gestão — o que cada termo significa, o que conecta as seis áreas do setor, e
as armadilhas de cada uma — fica **dentro do sistema**, em **Guias de uso → Gestão**
(`/guias/gestao`).

Ele está lá, e não aqui, de propósito: um guia precisa de botões, atalhos para as telas reais e uma
trilha visual que o markdown não dá. A decisão está em
[ADR-0001](../../adr/0001-guias-de-uso-in-app.md).

> **Esta página é um ponteiro e deve continuar curta.** Não acrescente conteúdo aqui: ela existe
> para o guia continuar sendo encontrado pela busca da Ajuda. Conteúdo novo vai na página do guia.

Gestão não é um fluxo único: são seis áreas independentes (Licitações, Certidões, Jurídico,
Qualidade, Patrimônio, Acessos e Credenciais), cada uma com sua própria rotina.

Para permissões, regras de negócio, detalhe de cada campo e mensagens de erro, veja o manual de
referência do setor: [Licitações](licitacoes.md), [Certidões](certidoes.md),
[Jurídico](juridico.md), [Qualidade](qualidade.md), [Patrimônio](patrimonio.md),
[TI](ti.md) e [Acessos](acessos.md).
