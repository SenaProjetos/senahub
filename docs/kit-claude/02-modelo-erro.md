# Modelo — Erro no sistema

Destino: SenaHub → **Suporte** → Novo chamado, categoria **Erro**. O título vai no campo Título, o resto na
Descrição. Anexe o print ou o vídeo no chamado (aceita imagem, vídeo e documento, até 100 MB).

---

**Título:** [Tela] — [o que deu errado, em poucas palavras]
_Exemplo: "Financeiro › Contas — baixa em lote some com a conta paga"_

**Onde**
- Caminho no menu: ...
- Endereço da página (copiar da barra do navegador): ...
- Computador ou celular: ...

**Quando**
- Data e hora aproximada da última vez: ...
- Desde quando acontece (funcionava antes?): ...

**Com quem**
- Meu usuário: ...
- Acontece com outra pessoa também? ...

**Dado envolvido**
Código do projeto, número do lançamento, nome do arquivo, pessoa, mês... o que identifica o registro: ...

**Passos para repetir**
1. ...
2. ...
3. ...

**O que eu esperava**
...

**O que aconteceu**
... (mensagem de erro copiada exatamente como apareceu, se houve)

**Frequência**
Sempre / às vezes / aconteceu uma vez.

**Impacto**
- Bloqueia o trabalho? Tem um jeito de contornar? ...
- Prioridade sugerida no chamado: Baixa / Média / Alta / Urgente

**Observado × suposição**
- Vi: ...
- Acho (não confirmado): ...

**Anexos**
Print da tela inteira (com o endereço visível) ou vídeo curto dos passos.

---

## Pronto quando

- [ ] Alguém que nunca viu o erro consegue repetir seguindo os passos.
- [ ] Tem data e hora, usuário e o dado envolvido.
- [ ] Esperado e acontecido estão separados.
- [ ] A mensagem de erro está copiada exata (ou está escrito que não houve mensagem).
- [ ] Tem print ou vídeo.
