# Guia do Comercial para iniciantes

O guia de formação do Comercial — o que cada termo significa, o caminho de ponta a ponta e as
armadilhas do setor — fica **dentro do sistema**, em **Guias de uso → Clientes e Comercial**
(`/guias/clientes-comercial`).

Ele está lá, e não aqui, de propósito: um guia precisa de botões, atalhos para as telas reais e uma
trilha visual que o markdown não dá. A decisão está em
[ADR-0001](../../adr/0001-guias-de-uso-in-app.md).

> **Esta página é um ponteiro e deve continuar curta.** Não acrescente conteúdo aqui: ela existe
> para o guia continuar sendo encontrado pela busca da Ajuda. Conteúdo novo vai na página do guia.

Os Guias de uso são visíveis a colaboradores internos. Se você é cliente, a documentação do que
você vê está em [Portal do cliente](../inicio/portal-cliente.md).

Para permissões, regras de negócio, detalhe de cada campo e mensagens de erro do Comercial, veja
[Comercial](comercial.md) — é o manual de referência, e continua sendo a fonte desses detalhes.
